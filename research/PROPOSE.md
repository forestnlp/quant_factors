# PROPOSE.md — 假设器作业规范（人肉彩排沉淀，L4 的 Prompt 母本）

> 用途：人肉彩排（人扮演 LLM 假设器）与 L4 实装（LLM 假设器）共用同一套规范。
> 假设器的输入 = 本文件 + `factorlib exprs`（去重索引）+ 失败教训；输出 = 一条 DSL 表达式。
> 每轮彩排后把新教训追加进"拒收规则"与"有效模式"，这就是回喂。

## 作业流程（每轮固定五步，机器可执行）

```
1. 读记忆    factorlib exprs            # 所有在册表达式+状态，查重防撞
2. 提假设    一句话经济逻辑（谁为什么会犯错误 → 我赚谁的钱）
3. 编译      alpha compile --name a_xxx --expr "..."     # 失败即拒收（语法/白名单）
4. IC 初裁   eval --json a_xxx          # 及格线：IS/neu |ICIR|>0.25 且 IS/OOS 同号
5. 组合终裁  backtest a_xxx --json -k 100 --rebal 10 --band 0.10,0.50 [--reverse]
             # 及格线（事前定）：IS 费后年化>0 且 Sharpe ≥ 现役基线；过线才准看 OOS 一次
6. 记账      factorlib add / record-eval / set-status    # 判决和理由写进 history
```

## 拒收规则（触发即停，不许"再调调看"）

1. **无经济逻辑**：说不出"谁犯错误、我赚谁的钱"→ 拒（数据 dredging 的根源）。
2. **重复发明**：与 `exprs` 中任一表达式算子/列组合等价 → 拒（先看失败记录）。
3. **IC 不及格**：IS/neu |ICIR| ≤ 0.25，或 IS/OOS 反号 → 拒并入库（rejected 留教训）。
4. **IC 强组合弱**：|ICIR|>0.5 但 band 组合 IS Sharpe < 基线 → **IC 榜≠钱榜**（结论14/彩排两轮实证），按组合判决，不许拿 IC 申辩。
5. **两腿皆弱**：交互/合成因子若每条腿单腿组合都未达标 → 默认拒（合成是提纯不是堆叠，结论13）。
6. **调参救活**：判决不过线后改 k/rebal/band 想救 → 拒（那是过拟合；一次假设=一次预注册判决）。**例外：方向修正不算调参**——回测方向必须与 eval IS/neu RankIC 符号强制联动（IC>0 → `--reverse` 做多高值端；彩排第2轮教训：方向选反 IS -11.8% 差点错杀好假设，核对语义是正确性修复非调参，同结论12③）。
7. **超窗口**：时序窗口 > 250 交易日 → 编译器直接拒（数据边界+内存）。

## 有效模式（两轮彩排 + 八场战役的证据，按优先级）

1. **负向量能类**最强（放量/高换手/竞价抢筹→未来差）：机制=散户注意力追逐，A 股散户占比高所以强。
2. **交互只在量级匹配时有效**：|ICIR| 0.71×0.47 的近邻对可交互；0.5 带×0.03 带只会互相稀释。
3. **独立性是合成前提**：相关 ≤0.25 的腿（auc vs 其余）才有合成价值。
4. **避开 D0 微票带**是现货多头的生死线：一律 band(0.10,0.50]。
5. **事件数据做减法**：稀疏事件（龙虎榜）适合做剔除过滤，不适合做多腿。
6. **财务面弱**（本区间）：只押 fin_cash_quality（唯一稳定），其余财务特征勿单独开猎。
7. **官方 101 是参照不是弹药**：榜单头部=正向结构类（与自家互补区），可仿其形、勿抄其值。

## 假设器 System Prompt 骨架（L4 实装用）

```
你是量化因子假设器。可用列见 <cols>，算子白名单 <ops>，近邻教训见 <history 摘要>。
每轮只提出 1 个新表达式，必须附一句话经济逻辑。禁止：与在册表达式等价改写、
纯技术堆砌（无逻辑）、窗口>250。收到裁判判决后：过线→提出该逻辑的最近变体；
拒收→读原因，换机制方向，不复盘旧方向。连续 N 轮同机制失败→该机制拉黑。
输出 JSON: {"name","expr","hypothesis","mechanism"}
```
