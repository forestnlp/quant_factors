# src/ — 正式代码区

本目录存放**经过验证、可复用**的正式代码，是项目的核心资产。

## 使用原则

- **正式性**：本目录代码必须经过验证、逻辑正确、可复用。
- **扁平结构**：模块文件直接放在 `src/` 下，按职责命名。
- **禁止污染**：引擎代码先写 `research/`，验证通过后再提升到此处。
- **接口清晰**：公开 API 使用类型注解与 docstring。

## 提升标准

从 `research/` 提升到 `src/` 需满足：

1. 逻辑正确，通过验证
2. 可复用（非一次性脚本）
3. 有清晰接口与文档
4. 不依赖实验环境
