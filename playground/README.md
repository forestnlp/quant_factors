# playground/ — 学习与实验区

本目录用于**边学习边开发**模式下的临时探索、学习笔记、实验脚本。

## 使用原则

- **临时性**：本目录内容为学习/实验性质，**不保证稳定、不保证正确**，随时可能被清理或重写。
- **不污染正式区**：实验代码不得直接进入 `src/`。只有经过验证、可复用的代码才提升到 `src/`。
- **命名规范**：每个实验建议放在独立子目录或独立文件，命名清晰（如 `playground/learn_qlib_expression.py`）。
- **验证闭环**：实验脚本应自带可验证的成功标准（参考 `AGENTS.md` 第 4 条），跑通后再决定是否提升到正式区。

## 提升到正式区的标准

一个实验代码满足以下条件才可提升到 `src/`：

1. 逻辑正确，通过验证（有明确成功标准）
2. 可复用（不是一次性脚本）
3. 有清晰接口与文档
4. 不依赖实验环境（如硬编码的临时路径）
