# src/ — 正式代码区

本目录存放**经过验证、可复用**的正式代码，是项目的核心资产。

## 使用原则

- **正式性**：本目录代码必须经过验证、逻辑正确、可复用。
- **扁平结构**：模块文件直接放在 `src/` 下，按职责命名（如 `data_loader.py`、`factor.py`、`backtest.py`）。
- **禁止污染**：学习/实验代码不得直接写入本目录，应先在 `playground/` 验证，再提升到此处。
- **接口清晰**：公开 API 使用类型注解与 docstring（参考 `AGENTS.md` 代码风格规则）。

## 提升标准

从 `playground/` 提升到 `src/` 需满足：

1. 逻辑正确，通过验证
2. 可复用（非一次性脚本）
3. 有清晰接口与文档
4. 不依赖实验环境
